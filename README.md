# L&L Estratégia (Lapis Lazuli Estratégia)

Site institucional: Consultoria Empresarial + Mentoria Executiva. Next.js 16 (App Router) + Tailwind 4.

- Conteúdo e contatos: `data/site.ts` (WhatsApp/e-mail/domínio ainda são placeholders).
- Artes do cliente: `public/brand/` (logo, banner Strategy/Execution/Growth, ícone da consultoria).
- `npm run brand` regenera as variantes do logo e a imagem da Mentoria Executiva a partir das artes originais.

```bash
npm install
npm run dev
```
